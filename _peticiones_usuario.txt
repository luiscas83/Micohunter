# ESPECIFICACIÓN ECOLÓGICA PARA EL MOTOR DE PREDICCIÓN DE SETAS

## Objetivo

Implementar en la aplicación un perfil ecológico individual para cada especie de seta.

El sistema debe estimar diariamente una:

**PROBABILIDAD DE FRUCTIFICACIÓN: 0–100**

La puntuación debe representar exclusivamente la adecuación de las condiciones meteorológicas y ecológicas para la aparición de cuerpos fructíferos.

NO interpretar la puntuación como garantía de que habrá setas.

El modelo debe considerar:

* precipitación reciente
* precipitación acumulada
* distribución de la lluvia
* temperatura
* temperatura del suelo si está disponible
* humedad relativa
* humedad del suelo si está disponible
* días secos consecutivos
* tendencia de temperatura
* época del año
* altitud
* tipo de vegetación
* tipo de suelo
* hábitat
* ventana temporal desde las últimas lluvias
* condiciones meteorológicas de las semanas anteriores

---

# IMPORTANTE: CONCEPTO DE "INCUBACIÓN"

No utilizar internamente el término "incubación" como si fuese un tiempo biológico exacto.

Utilizar:

`FRUITING_LAG_WINDOW`

Es decir:

**tiempo estimado entre un episodio meteorológico favorable y el aumento de probabilidad de aparición de cuerpos fructíferos.**

La lluvia no crea el micelio.

El micelio ya está presente en el suelo o sustrato cuando las condiciones ecológicas son adecuadas.

Por tanto:

LLUVIA
→ aumento de humedad disponible
→ condiciones térmicas adecuadas
→ activación/respuesta del micelio
→ formación de primordios
→ desarrollo del cuerpo fructífero
→ aparición observable

El modelo debe mostrar ventanas y probabilidades, no fechas exactas.

const gauss = (x, mu, s) => Math.exp(-((x - mu) ** 2) / (2 * s * s));

export function diaDelAnio(date = new Date()) {
  const ini = new Date(date.getFullYear(), 0, 0);
  return Math.floor((date - ini) / 864e5);
}

/**
 * Índice 0-100 para una especie.
 * @param sp   objeto de SPECIES
 * @param w    { dia, lluvia30, tMedia7, tMin7, hr }
 *             lluvia30[d] = mm caídos hace d días (d = 0..30; 0 = hoy)
 * @returns    { I, S, R, T, H }
 */
export function indice(sp, w) {
  const dist = Math.abs(w.dia - sp.pico);
  const S = gauss(Math.min(dist, 365 - dist), 0, sp.sS);

  let reff = 0;
  w.lluvia30.forEach((p, d) => { reff += p * gauss(d, sp.L, 3); });
  const R = Math.min(1, reff / sp.Ro);

  const T = w.tMin7 < sp.Tc ? 0 : gauss(w.tMedia7, sp.To, sp.sT);
  const H = Math.min(1, Math.max(0, (w.hr - 55) / 30));

  return { I: 100 * S * Math.pow(R, 1.5) * T * Math.pow(H, 0.5), S, R, T, H };
}

/** Ranking de todas las especies, de mayor a menor índice. */
export function ranking(w) {
  return SPECIES.map(sp => ({ sp, ...indice(sp, w) })).sort((a, b) => b.I - a.I);
}

/** Descarga y resume la meteorología de una coordenada. */
export async function meteo(lat, lon) {
  const url = "https://api.open-meteo.com/v1/forecast"
    + `?latitude=${lat}&longitude=${lon}&past_days=30&forecast_days=1`
    + "&daily=precipitation_sum,temperature_2m_mean,temperature_2m_min,relative_humidity_2m_mean"
    + "&timezone=auto";
  const j = await (await fetch(url)).json();
  const d = j.daily, n = d.time.length;
  const ult = (k, c) => d[k].slice(n - c);
  const media = a => a.reduce((x, y) => x + (y || 0), 0) / a.length;

  return {
    dia: diaDelAnio(),
    lluvia30: Array.from({ length: 31 }, (_, i) => d.precipitation_sum[n - 1 - i] || 0),
    tMedia7: media(ult("temperature_2m_mean", 7)),
    tMin7: Math.min(...ult("temperature_2m_min", 7)),
    hr: media(ult("relative_humidity_2m_mean", 7)),
    altitud: j.elevation,
  };
}

Depende mucho de la especie, de la intensidad/duración de la helada y de qué parte del ciclo esté ocurriendo. Para nuestro algoritmo sería mejor tratarla como un evento que modifica el estado, no como un botón de reset.

Por ejemplo:

    Helada ligera → penalización pequeña o incluso prácticamente ninguna en algunas especies.

    Helada moderada → ralentización del desarrollo.

    Helada fuerte/prolongada → penalización importante.

    Helada después de condiciones ya favorables → puede retrasar la aparición, pero no necesariamente elimina el potencial.

    Deshielo posterior + humedad + temperaturas adecuadas → el índice puede recuperarse progresivamente.

Además, distinguiría entre helada del aire y helada del suelo. Para nuestro modelo, la temperatura del suelo a 18 cm es especialmente útil porque puede permanecer relativamente estable mientras la superficie experimenta una helada.

En el primer caso hay un episodio frío prolongado; en el segundo, un evento aislado.
